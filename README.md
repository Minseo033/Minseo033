# 김민서

동양미래대학교 컴퓨터공학 전공 · 서울공고 기계과 졸업

앱과 웹을 개발하고 있습니다. 지금은 4인 팀 졸업작품 **HowMuch**를 웹으로 배포해 테스트하고, API와 화면을 계속 개선하고 있습니다.
